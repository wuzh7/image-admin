更新时间：2026-09-11

## 结论

- 浏览器当前登录的 `wuzh14551@gmail.com` 下，项目 `gen-lang-client-0758334318` 是免费层级。AI Studio 在 2026-09-11 显示 Gemini 3.8 Flash 限额为 5 RPM、250K TPM、20 RPD，近 28 天峰值为 7 RPM、2.01K TPM、20 RPD。该项目不是新加坡网关实际使用的付费生产 Key，因此这组限额不能代表生产环境。
- 主站当前 `IMAGE_INFRINGEMENT_WORKERS=8`，会瞬时发起最多 8 个请求。是否超限需要在生产 Key 所属 Google 项目的 AI Studio 限额页面核对，不能根据另一个免费项目推断。
- 批次 `2098100633007841282` 的 10 条失败均为 `UNPARSABLE_AI_RESPONSE`，不是 `GEMINI_RATE_LIMITED`；降低请求频率不能解决该批的格式失败。
- Google Gen AI Java SDK 1.68.0 默认最多尝试 5 次，但项目 `GatewayConfig` 已明确设置 `attempts(1)`，当前每张图片只调用一次。

## 已验证事实

Google 官方说明限额按项目而不是按 API 密钥计算，主要维度是 RPM、TPM 和 RPD；超限返回 `429 RESOURCE_EXHAUSTED`，实际限额以 AI Studio 为准。

- [Gemini API 限流文档](https://ai.google.dev/gemini-api/docs/rate-limits)
- [Gemini API 错误码](https://ai.google.dev/gemini-api/docs/generate-content/api-errors)

Gemini 结构化输出支持 JSON Schema、必填字段和枚举。官方同时要求应用对结构化结果进行语义校验，因为符合 JSON 结构不代表值一定符合业务要求。

- [Gemini 结构化输出](https://ai.google.dev/gemini-api/docs/structured-output?hl=zh-CN)

Java SDK 1.68.0 默认对 408、429、500、502、503、504 最多尝试 5 次；项目通过 `HttpRetryOptions.attempts(1)` 覆盖该默认值。

- [Java SDK 1.68.0 RetryInterceptor](https://github.com/googleapis/java-genai/blob/v1.68.0/src/main/java/com/google/genai/RetryInterceptor.java)
- [GatewayConfig.java](../../server/wuzh-ai-gateway/src/main/java/org/dromara/gateway/GatewayConfig.java)

## 工程建议

1. 使用生产 Key 所属 Google 账号登录 AI Studio，以该项目的 Gemini 3.8 Flash RPM/RPD 实际值设计生产并发。
2. 1000 张/20 分钟需要至少 50 RPM 和每日至少 1000 RPD；考虑抖动后，建议可用限额不低于 60 RPM、1200 RPD。
3. 格式问题独立修复：Gemini 返回必填的结构化 JSON；英文图片描述过长时截取，如模型偶发返回非英文，在同一次请求内通过明确字段说明约束模型输出英文，不另外调用翻译 API。
4. 保持一张一次、不自动重试；429、网络、5xx 和解析失败分别记录，交由页面手动重检。
