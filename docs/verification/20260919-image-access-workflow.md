# 图片权限与入库流程修复验证（2026-09-19）

## 交付范围

本次修改已用于本地 Compose 验证，尚未提交 Git 或发布生产。保留工作区原有订单、AI 网关、发布脚本等改动；下列说明只描述本次需求。

| 需求 | 最终行为 |
| --- | --- |
| 1–2 角色 | 表单与列表去掉角色 code、排序、编号；名称去除首尾空格后唯一，删除提示使用名称。RuoYi 内部权限键由服务端生成，保留框架鉴权所需字段。 |
| 3 用户与系统管理 | 去掉昵称、邮箱、手机号、性别输入；用户名唯一。关闭注册接口及入口，个人中心与消息盒子入口移除，个人中心接口关闭。只有管理员角色可访问系统管理；普通角色即使获得菜单权限仍不能绕过。 |
| 4 重复阈值 | 普通用户输入置灰，服务端拒绝自定义阈值；管理员仍可设置。 |
| 5 类目 | 去掉排序输入，按创建 ID 顺序展示；有图片的类目不能删除，类目管理仅管理员可操作。 |
| 7 图片详情 | 展示上传人、上传时间，以及 subjects、scenes、themes、visualStyles、colors；值直接来自 AI 对应数组，保留所有返回值。新检测 Prompt 要求这五类值为英文，历史结果保持原始值。 |
| 8 水印 | 登录后的页面显示用户名和时间水印。 |
| 9 人工审核 | 待审主图缩小到 200×160，每页 5 张。 |
| 10 审核后再次查重 | 最终入库事务重新查重；新出现的相似候选使之前的人工决定失效并返回待审；完全相同或相似度高于 95% 的图片不能重复入库。已人工确认且未新增超阈值候选的结果可继续入库。 |
| 11 图库筛选与替换 | 新增风险等级、图片 ID、上传用户名、上传时间筛选。管理员每次替换一张，成功后生成新图 ID；旧图归档到 replaced/旧ID/新ID/，保存操作者、时间、新旧 ID 和存储路径日志。失败保留旧图。 |
| 12 工作台 | 管理员按用户名筛选待办、操作与替换日志；普通用户不显示日志。历史未完成待办显示“今日必须完成”警告标签。 |
| 13 查看与导出 | 普通用户只能看到自己的图片，只可导出检测成功的 LOW 图片且同一用户不能重复导出；管理员不受上述限制。并发导出通过用户/图片唯一记录预占，正常失败释放预占。 |
| 14 登录默认值 | 删除硬编码默认账号密码；新浏览器会话输入为空，主动记住用户名的行为保留。 |
| 15 清空图库 | 管理员清空图片资产、批次、侵权任务/明细/调用日志、替换日志、导出记录、复查待办/进度、已知文件和向量；保留类目、账号、订单、系统配置。进行中的图片任务会阻止清空。补充清理入库失败或重启留下的确定复制路径。 |
| 16–17 并发与每日复查 | 最终查重与入库持有数据库互斥锁，已入库 SHA 受数据库唯一约束。北京时间每日 00:10 后复查前一完整上传日，并补跑未扫描日期和后来入库的历史图片；相似图片对生成管理员待办，失败重试且不重复生成同一图片对。扫描开始时间作为进度边界，扫描期间入库的历史图片在下一轮补查。 |
| 17 侵权检测顺序 | 入库成功后在事务内持久化检测任务，外部检测在提交后执行；同批次本轮入库完成后合并创建检测任务，保留既有批量分组和 Standard/Batch 路由。技术失败保持 FAILED，不变成 LOW。 |

## SSCD 视图核实

本地源码及生产正在运行的 JAR 字节码均为 **5 组查询视图**：原图、中心裁剪、旋转 90°/180°/270° 后的中心裁剪。本次没有改变这套视图、算法或阈值。此前“11 组”的描述已纠正；生产检查仅为只读。

## 验证证据

- 前端 `pnpm lint` 通过；已重新构建并更新本地前端。
- 针对系统权限、图片服务、上传、最终入库、复查、清空、侵权队列的 Surefire XML 共 **82 个测试，0 失败、0 错误、0 跳过**。
- 本地 HTTP 和隔离浏览器验证：角色/用户名重复拒绝、普通用户越权拒绝、非固定 ID 管理员可访问、注册/个人中心关闭、阈值服务端限制、图片归属隔离、四项筛选、AI 原始数组、类目删除限制、普通用户导出一次、管理员不限风险导出、用户名工作台筛选、登录输入为空、水印、表单删字段、管理员菜单隐藏、历史待办警告、待审每页 5 张。
- MySQL 10 个独立连接竞争同一个 SHA：1 个入库记录、9 个唯一约束拒绝。
- 本地真实后台调度处理 10 个已完成预检的相同 SHA 批次：最终 1 张 APPROVED、9 张 WAIT_REVIEW，匹配方式 EXACT_HASH。
- 实际替换验证：旧图 REPLACED、新图 APPROVED，新 ID 可搜索；读取归档与新图文件并校验各自 SHA，日志含管理员、时间及新旧 ID。
- 实际失败替换验证：故意缺失缩略图，入库返回 APPROVAL_FAILED，未提交的新图副本已删除，源文件及原 APPROVED 图片保留。
- 暂停本地 AI 网关验证检测失败，确认入库后才生成检测任务，失败结果为 FAILED / 无风险等级；随后恢复网关。
- MySQL 实际复查查询验证同秒入库会进入补查，早于扫描边界的图片不会重复补查；专属测试记录通过事务回滚清理。
- 测试账号、类目、资产、任务和文件仅使用临时专属 ID，验证后清理；未清空现有图库。

这些检查验证权限和最终入库一致性，不等同于“10 个用户上传整批真实图片”的吞吐量压测；受控缓存向量用于复现最终入库竞态，不代表 SSCD 召回准确率测试。旧图归档已验证本地存储，生产 OSS 尚未做写入验证。历史无关联、无法从数据库或确定路径追踪的 OSS 孤立对象不在按钮清理范围内。
